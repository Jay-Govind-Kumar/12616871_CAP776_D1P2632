# My Data, My Code

A personal **Daily Activity Tracker** created to record and understand how I spend my time each day.

## 📊 What I Track

- 😴 Sleep
- 🏃 Fitness
- 📚 Study
- 💻 Coding
- 🏫 Classes
- 🎯 Other activities
- 😊 Daily feeling
- ⭐ Satisfaction level
- ⚡ Energy level

All time values are recorded in **minutes**.

## 🎯 Purpose

The goal of this project is to track my daily routine, observe my habits, and understand how I use my 24 hours.
